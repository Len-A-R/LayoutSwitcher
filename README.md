# LayoutSwitcher

Минималистичная утилита для Windows, которая исправляет текст, набранный в неправильной раскладке, и меняет регистр без повторного ввода.

## Возможности

* Конвертация раскладки, например `ghbdtn` → `привет`, по реально установленным в Windows раскладкам
* Верхний, нижний и инвертированный регистр для любых алфавитов
* Обработка выделенного текста, последнего набранного слова или всей фразы
* Слово перед кареткой в браузерах, VS Code и Office — без буфера обмена
* Автозапуск с правами администратора для работы в окнах администратора
* Транслитерация (`привет` ↔ `privet`) и отмена последнего исправления
* Индикатор раскладки рядом с курсором
* Русский и английский интерфейс
* Отчёт для разработчика одним щелчком, проверка и установка новых версий в один щелчок
* Автоисправление: слова, набранные с Caps Lock (`пРИВЕТ` → `Привет`), и две заглавные (`ПРивет` → `Привет`)
* Шаблоны: сокращение и пробел (`;дата` → `18.11.2026`)
* Перевод и поиск выделенного текста в браузере
* Исправление раскладки и регистра текста в буфере обмена из меню трея
* Экспорт и импорт настроек, переносной режим (настройки в ini-файле рядом с программой)
* Настраиваемые сочетания клавиш и интервал двойного нажатия
* Пауза из меню трея и автоматическая пауза в полноэкранных приложениях
* Список программ-исключений (по умолчанию — программы захвата экрана)
* Защита полей ввода пароля
* Уведомления, если действие невозможно (окно администратора, изображение в буфере обмена)
* Отключение запроса «Включить залипание клавиш?» по пятикратному Shift
* Автозагрузка, трей-иконка текущей раскладки, защита от повторного запуска

## Горячие клавиши

По умолчанию:

| Комбинация | Действие |
| --- | --- |
| `Shift` + `Shift` | Конвертировать раскладку |
| `LCtrl` + `LCtrl` | ПРЕОБРАЗОВАТЬ В ВЕРХНИЙ РЕГИСТР |
| `RCtrl` + `RCtrl` | преобразовать в нижний регистр |
| `LCtrl` + `RCtrl` | ИнвЕрТиРоВаТь РеГиСтР |
| `LShift` + `RShift` | Транслитерация (`привет` ↔ `privet`) |
| `Caps Lock` + `Caps Lock` | Отменить последнее исправление (в том числе автоматическое) |
| `RAlt` + `RAlt` (правый Alt дважды) | Перевести выделенное |
| `LAlt` + `LAlt` (левый Alt дважды) | Найти выделенное в интернете |

LayoutSwitcher не может «перехватить» нажатие: его получает и программа в фокусе. Поэтому жестами служат только сочетания, безвредные для других программ. Оба Shift одновременно ничего не делают в Windows; двойной Caps Lock включает и сразу выключает Caps Lock, так что его состояние не меняется. `Ctrl+Shift` и `Alt+Shift` не используются — это системные переключатели языка.

Если в Windows включено «Отключать Caps Lock клавишей Shift», второй Caps Lock его не выключает; программа один раз предупредит об этом — тогда назначьте отмене другой жест.

Одиночное нажатие Alt в классических программах активирует строку меню, второе его снимает, поэтому при двойном Alt меню может коротко мигнуть (в Office — подсказки клавиш). `Alt+Shift`, `Alt+Tab` и другие сочетания с Alt жестом не считаются. На раскладках с AltGr правый Alt приходит как «фальшивый» Ctrl плюс правый Alt (в зависимости от драйвера клавиатуры — левый или правый Ctrl). Так устроена и русская раскладка Windows 10/11 (на AltGr+8 — символ `₽`), а также немецкая, польская и другие. Ctrl, пришедший вплотную (до 20 мс) перед правым Alt, программа считает частью AltGr: откатывает его влияние на распознавание жестов и игнорирует его отпускание. Поэтому двойной правый Alt работает и в этих раскладках, а набор символов через AltGr (например, `₽`) жестом не считается.

Настройки, сохранённые предыдущими версиями, получают новые сочетания автоматически (значение `SettingsVersion`), если эти жесты не заняты другими действиями. Учитывается, в какой версии появилось сочетание: действие, которое вы сами отключили в версии, где у него уже было сочетание, остаётся отключённым.

В окне настроек (двойной щелчок по иконке в трее или пункт **«Настройки...»**) каждому действию можно назначить любой из этих жестов или отключить его. Один жест управляет только одним действием: при назначении занятого жеста предыдущее действие отключается. Интервал двойного нажатия настраивается от 200 до 1000 мс (по умолчанию 500 мс).

Нажатие считается «касанием», только если модификатор отпущен быстрее интервала и вместе с ним не нажималась никакая другая клавиша. Поэтому `Alt+Shift`, `Ctrl+C`, ввод заглавных букв, длительное удержание и autorepeat не вызывают действий.

## Системные требования

* Windows 10 версии 1607 или новее / Windows 11
* Как минимум две раскладки клавиатуры

## Установка

Установщик `LayoutSwitcher-Setup-<версия>.exe` ставит программу для текущего пользователя (без прав администратора) в `%LOCALAPPDATA%\Programs\LayoutSwitcher` или, по выбору, для всех пользователей. При удалении он снимает автозапуск (включая задачу Планировщика) и по желанию удаляет настройки и журналы.

Без установщика:

1. Соберите проект в RAD Studio 12 для Win32 или Win64 (конфигурация Release).
2. Положите `LS.exe` в постоянное место и запустите.
3. Приложение свернётся в системный трей. Автозагрузка включается в окне настроек.

Если при запуске обнаружена устаревшая версия LayoutSwitcher (до 2.0), программа покажет её путь и предложит закрыть: две копии одновременно мешают друг другу. Повторный запуск уже работающей версии 2.x просто открывает окно настроек.

## Конвертация раскладки

Для каждой установленной раскладки через `ToUnicodeEx` строится таблица: какой символ даёт каждая физическая клавиша (по scan code) без Shift и с Shift. Символ ищется в таблице исходной раскладки и заменяется символом той же клавиши в целевой. Поэтому поддерживаются любые пары раскладок: украинская, белорусская, «Русская (машинопись)», немецкая, Dvorak и т. д.

* **Исходная раскладка** — та, в которой набрано больше букв, отсутствующих в других раскладках. При равенстве (только цифры, смешанный текст, две латинские раскладки) берётся текущая раскладка окна.
* **Целевая раскладка** — текущая раскладка окна, если текст набран в другой; иначе раскладка, которая была активна до текущей; иначе следующая в списке Windows.
* В смешанном тексте буквы «чужого» алфавита конвертируются в обратную сторону: `Delphi пример` → `Вудзрш ghbvth`.

### Слово, фраза, откат

Программа помнит всё, что набрано с момента последнего «прыжка» каретки (Enter, Tab, стрелки, Home/End, щелчок мышью, смена окна), включая пробелы, — до 300 символов. Повтор того же действия без ввода между нажатиями расширяет его:

| Нажатие | Было | Стало |
| --- | --- | --- |
| 1-е двойное `Shift` | `ghbdtn vbh` | `ghbdtn мир` — последнее слово |
| 2-е | `ghbdtn мир` | `привет мир` — остаток фразы, в том же направлении |
| 3-е | `привет мир` | `ghbdtn vbh` — откат всей фразы |

Если во фразе одно слово, второе нажатие сразу откатывает его. Пробелы после слова сохраняются. Смена регистра расширяется так же (слово → фраза), но не откатывается. После замены выделения повторная конвертация возвращает всё выделение.

Раскладка окна переключается на целевую через `WM_INPUTLANGCHANGEREQUEST`; если окно не отреагировало за 150 мс, запрос повторяется для окна верхнего уровня. Консоли (`ConsoleWindowClass`, Windows Terminal) этот запрос игнорируют, поэтому для них раскладка перебирается сочетанием `Win+Space` с проверкой после каждого шага.

## Как устроена обработка ввода

Клавиатура и мышь отслеживаются через Raw Input (`RIDEV_INPUTSINK` / `WM_INPUT`). LayoutSwitcher не встраивается в глобальную цепочку `WH_KEYBOARD_LL` и не может задержать ввод в других программах. Обработка `WM_INPUT` не выделяет память: движения мыши приходят сотнями в секунду.

Все операции с текстом выполняются в отдельном фоновом потоке (`uOperationWorker.pas`): запросы UI Automation, работа с буфером обмена, ожидание отпускания модификаторов, `SendMessageTimeout`. Главный поток только распознаёт жесты и отправляет запрос, поэтому трей и окно настроек всегда отвечают. Если операция не завершилась за 30 секунд, следующая всё равно будет принята, а запоздавший результат проигнорирован.

### Блокировка и сон

На время блокировки экрана, `Ctrl+Alt+Del`, запроса UAC и выхода из сна Windows переключается на защищённый рабочий стол, куда Raw Input не доставляется. Нажатие `Win+L` программа видит, а отпускание уже нет, поэтому раньше после пробуждения клавиша считалась зажатой и двойной `Shift` не срабатывал, пока её не нажмут снова. Теперь:

* перед каждым нажатием клавиши, которые считаются зажатыми дольше 250 мс, сверяются с физическим состоянием клавиатуры (`GetAsyncKeyState`);
* при блокировке, разблокировке (`WTSRegisterSessionNotification`) и выходе из сна (`WM_POWERBROADCAST`) состояние сбрасывается, а Raw Input регистрируется заново;
* запросы UI Automation ограничены 1 с на соединение и 2 с на операцию (`IUIAutomation2`) вместо 2 с и 20 с по умолчанию, а окна, которые не отвечают (`IsHungAppWindow`), пропускаются с уведомлением.

Собственный ввод выполняется через `SendInput` и помечается уникальным `dwExtraInfo`, чтобы синтетические события не попадали обратно в отслеживаемое слово. Символы отправляются по одному с паузой 8 мс: Блокнот Windows 11 и другие приложения на WinUI/XAML читают символ события `VK_PACKET` в момент обработки, а не постановки в очередь, и при пакетной отправке получали последний символ много раз (`дела` → `аааа`).

Перед операцией главный поток проверяет, что:

* активное окно не принадлежит программе из списка исключений;
* не запущено полноэкранное приложение (если включён соответствующий флажок; используется `SHQueryUserNotificationState` и проверка окна без рамки на весь монитор);
* целевое окно не запущено с более высоким уровнем прав. Windows (UIPI) молча блокирует `SendInput` в такие окна, поэтому вместо бесполезной попытки показывается уведомление.

Фоновый поток одним запросом UI Automation узнаёт, является ли элемент с фокусом полем пароля, и получает его выделение. В полях пароля (`IsPassword` в UIA или `ES_PASSWORD` у стандартного Edit) действие не выполняется, а нажатые клавиши не запоминаются.

Целевой текст определяется в следующем порядке:

1. Набранные слово или фраза из локального буфера — точный текст, clipboard не используется. В стандартных полях Edit/RichEdit (включая Блокнот) замена выполняется одним `EM_SETSEL` + `EM_REPLACESEL` после проверки, что текст перед кареткой совпадает с ожидаемым: это точнее эмуляции клавиш и даёт один шаг в истории отмены Блокнота. Для RichEdit учитывается, что позиции считают перевод строки одним символом, а `WM_GETTEXT` возвращает CRLF. В остальных программах — Backspace и ввод символов через `SendInput`.
2. Выделение или слово перед кареткой в стандартном Edit/RichEdit (включая Блокнот) — читается и заменяется напрямую.
3. Выделение через Windows UI Automation `TextPattern` (VS Code, браузеры, Office) — без изменения clipboard.
4. Слово перед кареткой через `TextPattern2.GetCaretRange`: диапазон расширяется назад по словам до пробела, поэтому `vbh,` (набранное в неправильной раскладке «мирб») берётся целиком. Диапазон выделяется (`Select`) и заменяется вводом. Так исправляется уже набранный текст, к которому вернулись курсором.
5. Только если ничего из перечисленного не подошло — контролируемый `Ctrl+C` fallback.

По журналам прежних версий UI Automation в Chrome, Яндекс Браузере и VS Code работает: «отказы» `selection_text` означали лишь отсутствие выделения. Именно эти случаи раньше уходили в `Ctrl+C`, теперь их покрывает п. 4.

Перед отправкой `Ctrl+C` и перед вводом текста утилита дожидается физического отпускания `Shift`/`Ctrl`/`Alt`/`Win` и даёт целевому окну короткое время на обработку `KeyUp`. Иначе VS Code иногда воспринимает копирование после двойного `Shift` как `Ctrl+Shift+C`.

### Буфер обмена

Clipboard fallback считается успешным только после изменения `GetClipboardSequenceNumber`. Перед копированием создаются независимые копии форматов (текст, HTML/RTF, metafile и другие блоки глобальной памяти), владельцем буфера на это время становится скрытое окно фонового потока. Восстановление выполняется через `SetClipboardData`; в восстановленный объект добавляется `ExcludeClipboardContentFromMonitorProcessing`, чтобы Windows не создавала повторную запись в истории буфера. Если `Ctrl+C` был проигнорирован и буфер не изменился, снимок освобождается без перезаписи.

Clipboard fallback не выполняется, если:

* в буфере изображение или список файлов (`CF_BITMAP`, `CF_DIB`, `CF_DIBV5`, `PNG`, `CF_ENHMETAFILE`, `CF_HDROP`) — повторная публикация скриншота стоила бы мегабайты на каждое нажатие и выглядела бы для ShareX («Watch clipboard») и истории буфера как новый снимок;
* владелец буфера не отвечает (`IsHungAppWindow`) — `GetClipboardData` для формата с отложенной отрисовкой синхронно ждал бы его ответа;
* владелец буфера — программа из списка исключений.

Служебные OLE-форматы (`DataObject`, `Ole Private Data`, `OleClipboardPersistOnFlush`) и `CF_OWNERDISPLAY` в снимок не попадают: они ссылаются на внутреннее окно и `IDataObject` прежнего владельца и после восстановления оставались бы «висячими». Снимок больше 16 МБ не создаётся.

## Транслитерация

Текст с кириллицей переводится в латиницу, иначе — в кириллицу: `Щука` ↔ `Shchuka`, `ЁЛКА` → `YOLKA`, `объём` → `obyom` (твёрдый и мягкий знаки опускаются). Обратное направление распознаёт сочетания `shch`, `zh`, `kh`, `ts`, `ch`, `sh`, `yo`, `yu`, `ya`, `ye`; `y` после гласной становится `й`, иначе `ы`. Для украинских букв: `ї` → `yi`, `є` → `ye`, `і` → `i`, `ґ` → `g`.

## Отмена

Действие «Отменить последнее исправление» возвращает текст, каким он был до последнего шага любого действия (конвертации, смены регистра, транслитерации, замены выделения), пока после него ничего не набрано. Перепечатывается только изменившаяся часть до каретки; после отмены конвертации раскладка возвращается к прежней. Повторить отменённое нельзя.

## Автоисправление и шаблоны

Срабатывает сразу после пробела, завершающего слово (вкладка **«Исправления»**):

* **Caps Lock** (включено по умолчанию): слово вида `пРИВЕТ` — первая буква строчная, остальные заглавные, не меньше трёх букв, без цифр — при включённом Caps Lock исправляется на `Привет`, а Caps Lock выключается. Если в Windows включено «Отключать Caps Lock клавишей Shift», программа выключает его нажатием Shift.
* **Две заглавные** (выключено по умолчанию): `ПРивет` → `Привет` для слов от четырёх букв, где заглавных ровно две и они стоят первыми. Список исключений редактируется (`VMware`, `OAuth`, `IPsec`, `МБайт`…).
* **Шаблоны** (включены): строки `сокращение=текст`; после ввода сокращения и пробела оно заменяется текстом. Подстановки `{date}`, `{time}`, `{datetime}`. По умолчанию есть `;дата` и `;время`. Сокращения лучше начинать с `;`, чтобы они не совпадали с обычными словами.

Программа не может перехватить нажатие, поэтому исправление выполняется уже после пробела: стиранием и повторным вводом либо, в стандартных полях ввода, одной заменой текста. Если вы успели напечатать что-то ещё, исправление отменяется: программа считает нажатия и ничего не стирает поверх нового текста. Любое автоисправление отменяется двойным Caps Lock.

## Перевод и поиск

Действия «Перевести выделенное» (двойной правый Alt) и «Найти выделенное в интернете» (двойной левый Alt) настраиваются на вкладке **«Сочетания»** (там же выбираются переводчик: Яндекс, Google, DeepL — и поисковая система: Яндекс, Google, Bing, DuckDuckGo). Берётся выделенный текст, если его нет — только что набранная фраза, затем слово перед курсором. Текст с кириллицей переводится на английский, остальной — на русский. Текст передаётся только в открытую ссылку браузера.

## Буфер обмена

Меню трея **«Текст в буфере обмена»**: исправить раскладку, ВЕРХНИЙ или нижний регистр, транслитерация. Программа читает текст из буфера, исправляет его и кладёт обратно — затем его можно вставить куда угодно, в том числе в окна администратора и удалённый рабочий стол.

## Индикатор раскладки

Флажок **«Показывать раскладку рядом с курсором при переключении»** выводит на 1,2 с значок `RU` / `EN` (код языка ISO 639) у текстового курсора, когда раскладка окна меняется. Значок никогда не получает фокус и пропускает щелчки мыши. Если программа не сообщает положение каретки (часть браузеров), значок появляется у указателя мыши. При простом переходе в окно с другой раскладкой значок не показывается.

## Язык интерфейса

«Как в Windows» (по умолчанию) выбирает русский для русского, украинского и белорусского языка интерфейса Windows и английский для остальных. Язык меняется сразу, без перезапуска.

## Отчёт для разработчика

Кнопка **«Собрать отчёт...»** (и одноимённый пункт меню трея) упаковывает в zip пять последних журналов, последний MiniDump и `system-info.txt`: версию, ОС, уровень прав, установленные раскладки, настройки и состояние автозапуска. Набранный текст в отчёт не попадает, потому что не пишется и в журналы. Если диагностика выключена, в отчёте будут только ранее записанные журналы.

## Обновления

Раз в сутки (первая проверка — через минуту после запуска) программа запрашивает `api.github.com/repos/Len-A-R/LayoutSwitcher/releases/latest`. Передаётся только заголовок `User-Agent` с номером версии. Пункт **«Проверить обновления»** проверяет сразу и сообщает результат. Автоматическую проверку можно отключить флажком в настройках.

Если опубликована более новая версия:

* **Программа установлена установщиком** и к релизу приложен `LayoutSwitcher-Setup-*.exe` — уведомление и пункт меню **«Установить версию …»**. По щелчку установщик скачивается во временную папку, его SHA-256 сверяется с контрольной суммой, которую GitHub публикует для файлов релиза, затем он запускается в тихом режиме (`/SILENT /WAITAPP=1`), программа закрывается, а установщик дожидается её выхода, обновляет файлы и запускает новую версию. Для установки «для всех пользователей» Windows запросит права администратора.
* **Программа запущена не из папки установки** (например, из папки сборки) — пункт **«Скачать версию …»** открывает страницу релиза: автоматическая установка создала бы вторую копию вместо обновления этой.

Тег релиза должен совпадать с версией в exe (`v2.2.0` для 2.2.0.0).

## Программы-исключения

По умолчанию LayoutSwitcher не работает в ShareX, Greenshot, Lightshot, Ножницах Windows (`SnippingTool.exe`, `ScreenClippingHost.exe`) и PicPick: не отправляет туда `Ctrl+C`, Backspace и текст и не трогает их данные в буфере обмена. Оверлей захвата сам использует модификаторы, а синтетический `Ctrl+C` заставил бы программу скопировать изображение. Список редактируется в окне настроек (имена exe через `;`), кнопка **«По умолчанию»** восстанавливает исходный набор.

## Пауза

Меню трея: **«Приостановить на 15 минут»**, **«на 1 час»**, **«до возобновления»** и **«Возобновить работу»**. Во время паузы иконка становится серой, жесты игнорируются, набранные символы не запоминаются.

## Залипание клавиш

Двойной `Shift` легко превращается в пять нажатий подряд, и Windows показывает запрос «Вы хотите включить залипание клавиш?». Флажок **«Отключить вызов залипания клавиш пятикратным нажатием Shift»** снимает у системной настройки `STICKYKEYS` флаги `SKF_HOTKEYACTIVE` и `SKF_CONFIRMHOTKEY`. По умолчанию флажок выключен: системные настройки специальных возможностей меняются только по явному выбору пользователя.

* Изменение действует только в текущем сеансе (`SystemParametersInfo` без `SPIF_UPDATEINIFILE`): профиль пользователя не меняется, а если программа завершится аварийно, исходная настройка вернётся при следующем входе в систему.
* При снятии флажка и при выходе из программы возвращаются только те флаги, которые сняла программа. Остальные параметры залипания клавиш, изменённые за это время, сохраняются.
* Если сочетание уже отключено в параметрах Windows, программа ничего не меняет и при выходе ничего не восстанавливает.
* После разблокировки и выхода из сна настройка применяется заново.
* Само залипание клавиш, если оно включено, продолжает работать: отключается только вызов запроса по пятикратному `Shift`.

## Настройки

Хранятся в `HKCU\Software\LayoutSwitcher`: `Gesture.<действие>`, `DoubleTapInterval`, `ExcludedProcesses`, `PauseInFullscreen`, `ShowNotifications`, `DisableStickyKeysHotkey`, `ShowLayoutIndicator`, `Language`, `CheckForUpdates`, `LastUpdateCheck`, `FixCapsLock`, `FixTwoCapitals`, `TwoCapitalsExceptions`, `SnippetsEnabled`, `Snippets`, `Translator`, `SearchEngine`, `SettingsVersion`, `EnableDiagnostics`. Повреждённые или противоречивые значения заменяются значениями по умолчанию.

### Экспорт, импорт и переносной режим

Кнопки **«Экспорт настроек...»** и **«Импорт настроек...»** на вкладке «Основные» сохраняют и загружают все настройки в файл `.ini` (UTF-8, раздел `[Settings]`). При импорте автозапуск и задача Планировщика не меняются: они относятся к конкретному компьютеру.

Если рядом с `LS.exe` лежит файл `LayoutSwitcher.ini`, программа работает в **переносном режиме**: все настройки читаются из него и записываются в него, журналы диагностики пишутся в папку `Diagnostics` рядом с программой, реестр не используется (кроме явно включённого автозапуска). Проще всего получить такой файл экспортом настроек. Текущий режим показан на вкладке «Основные».

## Автозапуск

Обычный автозапуск — ключ `HKCU\...\Run\LayoutSwitcher`.

Флажок **«Запускать с правами администратора»** заменяет его задачей Планировщика `LayoutSwitcher` (вход пользователя, `RunLevel=HighestAvailable`). Windows не даёт обычной программе вводить текст в окна, запущенные от администратора; задача запускает LayoutSwitcher с повышенными правами при каждом входе без запроса UAC. Подтверждение UAC нужно только при включении и выключении флажка. Задача создаётся из XML с нормальным приоритетом (по умолчанию у задач он понижен), без ограничения времени работы и с запуском от батареи. Ключ `Run` при этом удаляется, чтобы не стартовали две копии; при выключении флажка он восстанавливается.

Ключ `Run` Флажок не перезаписывает ключ при старте программы. Release-сборка, обнаружив, что в автозапуске прописан другой exe, обновляет путь на себя; Debug-сборка только пишет об этом в журнал. Это исключает ситуацию, когда устаревший exe при каждом входе в систему заново прописывал себя в автозапуск.

## Диагностика

Журнал ведётся в `%LOCALAPPDATA%\LayoutSwitcher\Diagnostics` и включается флажком **«Вести диагностический журнал»**. Первая строка каждого журнала содержит версию программы (`session.start version=...`), разрядность и тип сборки. Сам набранный или выделенный текст в журнал не записывается.

Запись потокобезопасна. Файл больше 2 МБ продолжается в следующей части (`-part2.log` и т. д.). В папке хранится не больше 10 журналов общим объёмом до 5 МБ и 3 последних MiniDump; более старые файлы удаляются при запуске.

При исключении создаётся MiniDump (`.dmp`). Файл `last-session.running`, оставшийся после завершения процесса, помечает незавершённый сеанс.

## Тесты

`Tests\run-tests.cmd` собирает и запускает модульные тесты DUnitX (Win64; в RAD Studio 12 DUnitX поставляется только для Win64). Покрыты конвертация раскладки (включая сверку с системными таблицами US/RU, если они установлены), смена и инверсия регистра, выбор исходной раскладки, автомат жестов (двойные нажатия, аккорд, `Alt+Shift`, `Ctrl+C`, autorepeat, переполнение счётчика тиков, залипшие после блокировки клавиши, жест двух Shift, двойной Caps Lock), цепочка «слово → фраза → откат», отмена, транслитерация, автоисправления, шаблоны, ссылки перевода и поиска, экспорт и импорт настроек, сравнение версий и разбор настроек.

### Сценарные тесты

`Tests\Integration\run-integration.cmd` проверяет на настоящих полях ввода работу фонового потока: цепочку «слово → фраза → откат» с переключением раскладки, отмену, смену регистра, транслитерацию, замену выделения и слова перед кареткой через `EM_REPLACESEL`, пропуск поля пароля. Тестовое окно получает фокус и около десяти секунд вводит текст само в себя; ввод отправляется, только пока оно на переднем плане, иначе прогон прерывается. Во время запуска не трогайте клавиатуру и мышь.

В Debug-сборке включён отчёт об утечках памяти при выходе (`ReportMemoryLeaksOnShutdown`).

## Сборка релиза

`build-release.cmd` собирает обе платформы, запускает модульные тесты, подписывает exe и складывает результат в `dist\`. `build-release.cmd /dry` только показывает шаги.

* Подпись (необязательно): `LS_SIGN_PFX` + `LS_SIGN_PASSWORD` или `LS_SIGN_THUMBPRINT` (сертификат в хранилище пользователя, в том числе на USB-токене), `LS_SIGN_TIMESTAMP` — сервер меток времени. Используется `signtool.exe` x64 из Windows SDK.
* Установщик собирается, если установлен Inno Setup 7 или 6 (`ISCC.exe` в стандартной папке или путь в `LS_ISCC`); скрипт — `installer\LayoutSwitcher.iss`. Готовый установщик тоже подписывается.

### Подпись внутри организации (самоподписанный сертификат)

Подходит, если программа ставится только на компьютеры, которыми вы управляете. Для распространения через интернет нужен сертификат от доверенного центра сертификации.

```powershell
# 1. Создать сертификат подписи кода (один раз)
$cert = New-SelfSignedCertificate -Type CodeSigningCert -Subject "CN=Len-A-R Soft" `
  -CertStoreLocation Cert:\CurrentUser\My -KeyAlgorithm RSA -KeyLength 3072 `
  -NotAfter (Get-Date).AddYears(5)
$cert.Thumbprint
# 2. Открытая часть для раздачи на компьютеры
Export-Certificate -Cert $cert -FilePath LayoutSwitcher-codesign.cer
```

На каждом компьютере `.cer` импортируется в хранилища компьютера «Доверенные корневые центры сертификации» и «Доверенные издатели» (вручную через `certlm.msc` или групповой политикой). Затем сборка: `set LS_SIGN_THUMBPRINT=<отпечаток>` и `build-release.cmd`. Закрытый ключ остаётся только на машине сборки; файл `.cer` секретом не является.

## Ограничения

* Для окон, запущенных от администратора, LayoutSwitcher тоже должен работать с правами администратора (см. «Автозапуск»).
* Перебор раскладки через `Win+Space` в консоли переключает языки, а не раскладки одного языка.
* Игры, защищённые поля и некоторые редакторы с Raw Input могут не принимать синтетический ввод.
* Максимальная длина отслеживаемой фразы — 300 символов.
* Символы, набираемые через AltGr, и мёртвые клавиши в таблицы конвертации не входят.
* Без сертификата исполняемый файл не подписан: SmartScreen может предупредить при первом запуске (см. «Сборка релиза»).
* Транслитерация однозначна только в сторону латиницы: `ъ`/`ь` теряются, `й`/`ы` различаются эвристикой.
